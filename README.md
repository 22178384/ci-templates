# ci-templates

> 可直接复制到项目里的 GitHub Actions 工作流模板。

## 模板
- [python-ci.yml](.github/workflows/python-ci.yml)：Python 测试 + 覆盖率
- [node-ci.yml](.github/workflows/node-ci.yml)：Node 安装 / 构建 / 测试

## 用法
把 `.github/workflows/` 下的文件复制到你的仓库即可，按需改 Python / Node 版本。
